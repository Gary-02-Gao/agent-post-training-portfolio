## 我在研究什么

**实际执行证据，何时能帮助我们作出更值得投入的 Agent 后训练决策？**

工具型模型需要根据证据和环境状态选择补查、补证、执行或停止。这个项目把实际行动、环境结果和最终回复联系起来，再用对照实验判断：下一步是否值得训练，或者简单工程办法已经足够。

退款是当前的合成实验环境；研究关注的是 Agent 的学习、评价和干预选择。

## 主要观察

- **第一次 SFT：**8 个配对完整任务，人工文字＋操作联合通过从 **1/8 到 5/8**。
- **停止历史干预：**受控完整任务复测从 **6/8 到 8/8**；局部下一步另计 **0/4 到 4/4**。
- **竞争性简单对照：**新一批任务中，诊断方案 D 与常规方案 S 为 **6/8 对 8/8**，停止均为 **2/2**。最终选择 S，保留“诊断方案没有显示额外收益”的结果。

各批任务、模型和评价目的不同，不能合成一个总体成功率。结果来自同一合成任务族；停止复测使用已见完整实例，局部决策不等同于独立完成任务。[结果解释](docs/FINDINGS.md)

## 我重视的判断

最终回答正确，不能抵消此前的错误操作。训练后表现更好，也需要先排除输入混杂。具体干预改善旧基线，不代表诊断方法优于有竞争力的简单办法。因此，研究中既保留了 SFT 正向案例，也根据竞争比较接受了更简单的工作基线。[研究判断案例](docs/RESEARCH_JUDGMENT.md)
